# Terra Incognita — Demo UI (`frontend/`)

Interactive *training‑timeline simulator* for the continual‑learning story:
show naive fine‑tuning catastrophically forgetting earlier disaster regions,
and experience replay (ours) retaining them.

Built with **Vite + React + TypeScript + Recharts**. No backend, no live
training — every number is precomputed.

## Run (one command)

```bash
bash run.sh            # installs deps, generates assets, exports real data, then `npm run dev`
```

or manually:

```bash
npm install           # once
npm run dev           # http://localhost:5173
```

Production build (for a rock‑solid demo):

```bash
npm run build && npm run preview
```

## Pages

| Page | What it shows |
|---|---|
| Overview | Problem in 3 bullets + a 3‑step schematic (`public/assets/overview.png`). |
| Simulator | Regime tabs (Naive / Joint / Replay), **reset** + **next task** buttons, a task strip (Hurricane → Tsunami → Wildfire), the accuracy matrix table, a per‑region bar chart with the "forgotten" sliver drawn, and a forgetting ledger comparing all regimes at the current step. |
| Domain Distance | Forgetting vs inter‑region feature distance (`public/assets/domain_distance.png`). |
| Qualitative | Pred vs true labels on satellite building patches, color‑coded (green correct / red wrong). |

## Where to plug in real pipeline results

1. Run the full pipeline in the **repo root**: `bash run.sh`.
2. From `frontend/`: `npm run data`
   (`node tools/export-results.mjs`).
3. It reads `../results/{naive,joint,cl}_matrix.json` (fraction matrices with
   `NaN` for unseen regions) → writes `public/data/results.json` in the app's
   schema, and copies the real `../plots/domain_distance.png` over the placeholder.

If `public/data/results.json` is absent the app silently falls back to the
hardcoded demo matrices in `src/data/results.ts` (header comment documents how
to extend the number of tasks/regions). Qualitative labels default to
`src/data/qualitative.ts` unless `public/data/qualitative.json` exists.

Placeholder images (overview schematic, distance scatter, synthetic building
tiles) are generated by `tools/make_assets.py`:

```bash
python3 tools/make_assets.py          # or: npm run assets
```

## Scripts

- `npm run dev` — Vite dev server (HMR)
- `npm run build` — typecheck (`tsc`) + production bundle to `dist/`
- `npm run preview` — serve the production build
- `npm run data` — export real pipeline results (see above)
- `npm run assets` — regenerate placeholder images / qualitative tiles

## Design notes

- Visual language: an editorial **field‑report / mission‑console** skin — serif
  display type, mono uppercase data labels, hairline rules, paper grain, and
  figures/tables captioned like a written report. Deliberately avoids the
  "generic AI dashboard" look (no pastel gradient cards, no eyebrow labels on
  every card, no pillow shadow clusters).
- **Simulator state** lives in `SimulatorPage` (`taskIdx`) + `App` (`method`);
  switching method keeps the current task step.
- **Forgetting is drawn, not just measured**: bars stack *lost* (pale) under
  *retained* (solid), so the light sliver equals the region's accuracy drop vs
  its own best. The same number is repeated as `avg forgetting` in the ledger
  table next to the chart.
- Metrics mirror `src/utils.py::average_forgetting` so UI numbers agree with
  the written report.
